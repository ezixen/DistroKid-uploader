DistroKid Uploader — how to use (short)
=======================================

Latest always (GitHub):
  https://github.com/ezixen/DistroKid-uploader
  https://github.com/ezixen/DistroKid-uploader/releases/latest
  ZIP:  https://github.com/ezixen/DistroKid-uploader/releases/latest/download/DistroKid-uploader.zip
  EXE:  https://github.com/ezixen/DistroKid-uploader/releases/latest/download/DistroKid-Uploader-exe.zip
  (Unpack → DistroKid-uploader\ folder is created for you.)

EASIEST (no install) — EXE
--------------------------
1. Unpack the ZIP → DistroKid-uploader\ folder appears
2. Edit upload-settings.txt once (beside the exe, or in the app folder)
3. Open app\DistroKid-Uploader\ and double-click DistroKid-Uploader.exe
4. Log into DistroKid in the Chrome window (once; finish 2FA if asked)
5. Paste an album folder path, press Enter; repeat for more albums
6. Review the form in Chrome; you push/upload

You can run several DistroKid-Uploader.exe at once on the same debug Chrome:
each instance opens its own new tab and keeps using it.

Needs Google Chrome.
Chrome login is stored in %LOCALAPPDATA%\DistroKid-Uploader\ (not in the app folder),
so you can delete the unpacked folder anytime (any drive).
After each quit: caches/temp cleared; DistroKid login kept.

Script path (PowerShell steps)
------------------------------
0. Run 0_associate_ps1.bat (first time — before install)
   - Associates .ps1 with built-in Windows PowerShell:
     %SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe
   - Or just use the .bat step files / the EXE above.

1. Run 1_install.bat (or 1_install.ps1) — first time only
   - Allow the Administrator / UAC prompt.
   - Installs the newest Python 3.x from winget if you do not
     already have Python 3.10+, then pip packages.

2. Run 2_start_chrome.bat (or .ps1) and log into DistroKid (once per PC)

3. Optional — 3_check_titles.bat

4. Run 4_distrokid_uploader.bat
   - Paths separated by ; also work in the script path.

If the album title already exists on DistroKid → WARNING, no overwrite
(unless --force). This tool never final-publishes.

How filenames work
------------------
  01. ezixen - intro.wav
  number, artist, " - ", title, .wav
  Underscores in titles become ?
  Trailing "..." in titles is kept (e.g. yes, and...)

Cover: largest .jpg / .jpeg in the folder.
Settings: edit upload-settings.txt (prices, AI, credits, Audiomack, etc.)

More detail: README.md
Playbook: docs\DISTROKID_UPLOAD.md

If stuck Chrome / Temp folders ever happen
-----------------------------------------
  If C:\Temp (or D:\Temp) still has stuck playwright_* / chrome-canary*
  / chrome-debug-profile* / old local-secrets folders you cannot delete:

  1) docs\DEV_REMOVE_STUCK_BROWSER_PROFILES.md
  2) Safe Mode (Minimal) via msconfig
  3) Run docs\SAFE_MODE_DELETE_STUCK_CHROME.bat as Administrator
  4) Turn Safe boot OFF, reboot normally

  That is the solution for this class of leftover.
